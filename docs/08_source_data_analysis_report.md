# รายงานวิเคราะห์เอกสารประกอบระบบ PLOs

## บทสรุป

ได้รับเอกสาร 6 ไฟล์ ประกอบด้วยคู่มือเกณฑ์ EdPEx 2567–2570, คู่มือรับรองสถาบันฉบับปรับปรุง พ.ศ. 2568, คู่มือ M-AUN-QA V.4, Curriculum Mapping หลักสูตร พ.ศ. 2565, หลักสูตรพยาบาลศาสตรบัณฑิตฉบับปรับปรุง พ.ศ. 2565 และหลักสูตรฉบับแก้ไข พ.ศ. 2570 ในรูปแบบ DOCX/PDF/XLSX เอกสารเกณฑ์ทั้งสามกลุ่มเหมาะสำหรับใช้เป็น **แหล่งอ้างอิงและ standard mapping** ไม่ใช่ข้อมูลนักศึกษาโดยตรง

ไฟล์ที่นำไปทำเป็นข้อมูล import-ready ได้ทันทีคือ Curriculum Mapping Excel เนื่องจากไม่มีเลขประจำตัวประชาชน ชื่อ หรือข้อมูลส่วนบุคคลของนักศึกษา จึงปลอดภัยกว่าการนำเข้า roster จริง ผลการแปลงได้ 198 mapping records จาก 49 รายวิชา ครอบคลุม PLO1–PLO10 และระดับ I/R/M ดังตารางต่อไปนี้

| รายการ | ผลวิเคราะห์ |
|---|---:|
| ไฟล์ Curriculum Mapping | `Curriculummapping-2565วพบกรุงเทพพฤษภาคม65.xlsx` |
| จำนวนรายวิชา | 49 |
| จำนวน mapping records | 198 |
| PLO ที่ตรวจพบ | PLO1–PLO10 |
| ระดับ R / M / I | 106 / 66 / 26 |
| ชั้นปีที่พบ | 1, 2, 3, 4 |
| ไฟล์ผลลัพธ์ | `docs/source_analysis/curriculum_mapping_import.csv` |

## การแบ่งประเภทไฟล์

| กลุ่มเอกสาร | ไฟล์ | การใช้ในระบบ |
|---|---|---|
| เกณฑ์คุณภาพ | EdPEx, M-AUN-QA, Accreditation Manual | เติม `standard_mapping`, evidence checklist และรายงาน CQI/SAR |
| หลักสูตร | หลักสูตร พ.ศ. 2565 และเอกสารแก้ไข พ.ศ. 2570 | ตรวจสอบ PLO, CLO, โครงสร้างหลักสูตร, หน่วยกิต และ version control |
| Mapping | Curriculum Mapping พ.ศ. 2565 | เติม courses และ curriculum_map หลังยืนยัน sub-PLO/course metadata |

## ผลการตรวจฐานข้อมูล Supabase

ฐานข้อมูล PLOs มี curriculum version `2565` สถานะ active และ version `2570` สถานะ draft พร้อม PLO 10 รายการต่อ version แต่หลักสูตร 2565 ยังมี **sub-PLO 0 รายการ** และ `curriculum_map` ยังมี 0 records ดังนั้นยังไม่ควรนำ CSV เข้าโดยตรง เพราะจะทำให้ mapping ที่มีรหัส 1.1, 1.2, … ไม่สามารถผูกกับ entity ที่มีคำอธิบายและ foreign key ได้อย่างถูกต้อง

การนำเข้าที่ถูกต้องควรทำตามลำดับนี้: ยืนยันรายการ sub-PLO และคำอธิบายจากเอกสารหลักสูตรอย่างเป็นทางการ, เติมข้อมูลรายวิชาพร้อม semester และ course_type, เติม sub-PLO, แล้วจึง upsert `curriculum_map` โดยผูกกับ UUID ที่อ่านจากฐานข้อมูล ไม่ hardcode UUID ในไฟล์ข้อมูล

## ข้อมูลที่ยังไม่มีในไฟล์แนบ

เอกสารชุดนี้ยังไม่มี student roster, student code, admit year, national ID hash, course enrollment, assessment methods, CLO descriptions หรือผลคะแนนจริง จึงยังไม่ควรสร้างข้อมูลนักศึกษา/คะแนนจำลองหรือ import ข้อมูลบุคคล การเปิดใช้งาน production ต้องได้รับไฟล์ roster ที่ผ่านการอนุมัติและจัดเตรียมเป็น CSV ที่ลดข้อมูลส่วนบุคคลแล้ว รวมถึงกติกาการจับคู่บัญชีผู้ใช้กับนักศึกษา

## สถานะการนำเข้า

ไฟล์ CSV ถูกสร้างไว้เพื่อการตรวจสอบและ staged import แล้ว แต่ **ยังไม่ได้เขียนเข้า Supabase** เพราะข้อมูล sub-PLO และ metadata รายวิชายังไม่ครบ การหยุดไว้ที่ขั้นนี้ช่วยป้องกันการสร้าง mapping ผิดหลักสูตรหรือทำให้ผล Dashboard อ้างอิงข้อมูลที่ตรวจสอบย้อนกลับไม่ได้

## ขั้นตอนถัดไปที่ต้องยืนยัน

ผู้ดูแลหลักสูตรควรยืนยันรายการ sub-PLO ของหลักสูตร 2565 ให้ตรงกับเอกสารฉบับที่ใช้งานจริง จากนั้นยืนยัน semester, course_type และการตีความระดับ I/R/M ของแต่ละช่องใน Excel เมื่อได้รับการยืนยันแล้วจึงสามารถสร้าง migration staged และตรวจจำนวน records ก่อน commit ได้


## ผลตรวจเอกสารหลักสูตรฉบับแก้ไขเพิ่มเติม

การอ่าน DOCX หลักสูตรฉบับแก้ไขพบคำอธิบาย PLO ระดับหลักสูตรอย่างชัดเจนจำนวน 9 รายการ (PLO1–PLO9) เช่น ศาสตร์ทางการพยาบาล การปฏิบัติแบบองค์รวม จริยธรรม ภาวะผู้นำ วิจัย เทคโนโลยีดิจิทัล การพัฒนาตนเอง และการสื่อสาร อย่างไรก็ตาม รายการดังกล่าวอยู่ในตารางผลลัพธ์ระดับ PLO และไม่ได้ให้ canonical sub-PLO codes ที่ตรงกับ 198 records ใน Excel อย่างครบถ้วน อีกทั้งเอกสารฉบับนี้มีความแตกต่างด้านถ้อยคำและจำนวน PLO จาก seed หลักสูตร 2565 ในฐานข้อมูล จึงยังไม่ควรใช้คำอธิบายนี้แทนข้อมูลเดิมโดยอัตโนมัติ

ข้อสรุปการนำเข้ายังคงเป็น **staged only**: สามารถใช้ PLO descriptions เป็นเอกสารประกอบการ review และใช้ Excel เป็น mapping candidate ได้ แต่ต้องมีผู้รับผิดชอบหลักสูตรยืนยัน version, PLO10, รายการ sub-PLO, semester และ course_type ก่อนสร้าง migration ที่เขียนข้อมูลจริง
