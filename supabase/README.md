# Supabase Database Assets

โฟลเดอร์นี้เก็บ migration ที่เป็น source of truth สำหรับฐานข้อมูลของ PLOs Assessment System การนำไฟล์ใน `migrations/` ไปใช้ต้องทำใน Supabase SQL Editor หรือ Supabase CLI โดยอ่านคู่มือ `docs/INSTALLATION_GUIDE.md` ก่อนเสมอ

> ห้ามใส่ `service_role` key, เลขบัตรประชาชนจริง หรือข้อมูลนักศึกษาจริงในไฟล์ migration หรือ repository นี้
